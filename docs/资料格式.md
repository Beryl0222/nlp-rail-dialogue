# 数据约定

utterances为训练用意图样例，slots允许为空，dialog中的turns为未裁定输入，不含期望答复。products完全虚构，不表示真实铁路服务；policy提供产品解释边界。today和timezone用于相对日期，travellers/tickets是客服已知事实。个人指代需通过当前回合证据确定，不能用性别猜测。

全部人物、产品、组织和业务记录均为本地合成资料。原文使用UTF-8，文本区间按原文Unicode码点左闭右开计数；不同修订的区间不互换。ID只用于引用，不携带判定结果。data中的学习标记是已有人工例子，可用以训练，业务记录的处理结果仍需由产品产生。
